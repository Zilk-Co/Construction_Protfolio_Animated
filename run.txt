============================================================
  Arch Portfolio — Windows Run Commands
============================================================

--- Step 1: Install Dependencies ---
pnpm install

--- Step 2: Configure Environment ---
Copy `.env.example` to `.env` at the repo root and fill in real values
(DATABASE_URL, SESSION_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD, GEMINI_API_KEY).
The API server loads `.env` automatically — no manual env exports needed.

--- Step 3: Push Database Schema ---
$env:DATABASE_URL="<your-neon-connection-string>"
pnpm --filter @workspace/db run push

--- Step 4: Start Backend API Server (Terminal 1) ---
pnpm --filter @workspace/api-server run dev

--- Step 5: Start Frontend Dev Server (Terminal 2) ---
pnpm --filter @workspace/portfolio run dev

============================================================
  Access:
    Frontend:    http://localhost:5173
    API Server:  http://localhost:5000/api/healthz
    Admin Panel: http://localhost:5173/admin-panel
============================================================

  Features:
    - Full admin panel for projects, machinery, services, documents
    - Image/document upload support (base64 storage in DB)
    - AI assistant (Gemini) — set GEMINI_API_KEY / GEMINI_MODEL
    - Neon PostgreSQL database connected
============================================================

  Deployment:
    Frontend -> Vercel  (artifacts/portfolio, /api proxied to Railway via vercel.json)
    Backend  -> Railway (artifacts/api-server)
    Database -> Neon PostgreSQL (see DEPLOYMENT.md)
============================================================

  Rebrand migration (one-off, idempotent):
    $env:DATABASE_URL="<your-neon-connection-string>"
    pnpm --filter @workspace/scripts run db:rebrand
============================================================
